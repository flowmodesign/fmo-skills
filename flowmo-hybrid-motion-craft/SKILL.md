# Hybrid motion craft

Decide editability per visual element, not per whole scene. Exact text, flat icons, controls, strokes, borders, diagrams and requested editable graphics remain native. Cinematic environments, complex material/light, dimensional objects and backgrounds may be generated video plates when the user permits. A 3D request does not mean every object must be hand-built. Preserve a real logo asset; never ask generation to invent it. Generate clean plates without baked copy, logos or editable controls, leaving the planned negative space for overlays. Generation requires an actually callable producer, supported inputs, legal duration/resolution and the user's budget/approval; this skill grants none of those.

Read the brand's visual references as well as tokens. A black/blue palette alone does not reproduce its design system. Record the reference's corner radii, border treatment, surface layering, icon language, material, light direction, accent roles, type hierarchy and content density. User-supplied examples override an earlier proposed look. Use purposeful edge light or glow when the actual reference calls for it; avoid indiscriminate bloom. Match materials, light and depth across generated and native elements.

Build one finished style frame for each signature scene before repeating it. A finished software card has a designed silhouette, rounded boundary, surface, hairline edge, icon, actual content, readable label and a considered active state. A tunnel needs a varied collection of relevant content with depth, perspective, occlusion and camera travel; twenty-four copies of one raw image are a placeholder. Reuse a small set of distinct existing brand/reference assets and native card designs before buying new assets. Explain a genuine missing asset and generate only the required one within the approved budget.

Inspect the owning editor's import and construction capabilities instead of assuming every engine shares them. Follow its rendition for tools, units, stable targets and supported values. Read import diagnostics; never rasterize text or flat graphics the user requires editable. Unsupported mappings must be replaced with supported native construction or a disclosed generated plate, never silently dropped. CSS perspective is not evidence of an editable shared 3D world.

Compose first, then choreograph with the editor's native engine. Define the dominant subject, foreground/midground/background, light falloff, readable contrast, safe areas and frame coverage. Use real product interactions: a cursor connects a wire, a node reacts, an editable label changes, a palette choice updates a visible result. Entry, action, settle and exit must express the interaction. Add accents to these events rather than an opacity fade on every object. Use supported camera moves, stagger, shape/path drawing and text animators. Preserve shot-specific timing and transitions from the source.

Review full-size pixels at matched reference moments, not only layer/keyframe counts. Fail plain placeholder panels, repeated content, missing shapes/borders/icons, source-brand leftovers, unsupported controls and motion that reads as an offline layout. Inspect every scene and transition in playback, plus the actual native editability and audio ending. Repair failed signature scenes in place, then render and verify the playable output. State any unverified criterion honestly; numerical motion, an imported precomposition or an opened editor is not creative acceptance.
