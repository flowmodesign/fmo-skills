# Rendition: compositor

On `flowgen-chat`, discover the active editor with `get_open_compositor` and use `invoke_compositor_tool` for its declared tools; on `assistant-video`, use the declared direct compositor tools. Inspect `read_compositor`, source assets and the actual FPS. Get exact supported construction examples from `get_compositor_authoring_contract` when callable.

Place successful selected generated plates as actual media assets; layer native text/shapes/controls independently. Use bounded `apply_compositor_batch` operations with stable IDs, revisions and preconditions. Native numeric keyframes use integer frames and `hold`, `linear` or `bezier` easing, not GSAP ease strings. Read the schema for paths, masks, effects, text animators and shared 3D worlds/cameras before constructing them.

When using `import_compositor_motion`, inspect its real HTML/GSAP translation diagnostics and saved native results. Browser-layout import can translate supported rounded silhouettes, gradients, plain SVG geometry, shadows and filter chains, but rich SVG can rasterize. Inspect each requested editable element, replace unsupported mappings, and keep source scripts out of other editors. A generated complex plate is acceptable only inside the agreed editability boundary.

Review saved layer/keyframe coverage, rendered reference moments and continuous playback. `review_compositor_motion` is numerical diagnosis; pair it with rendered motion when judging smoothness. Check plate/native timing, transitions, safe areas, copy, audio ending and the actual playable output. An imported precomposition or an opened editor is not creative acceptance.

Browser-backed HTML is another editable source, not native conversion. Read `get_compositor_html_contract` before choosing. Prefer native media/audio and supported native appearance; use `import_compositor_html` when browser typography, CSS or SVG fidelity is needed. Identified elements become regular layers and identified containers become native precomps accepting native children. Use literal paused `fromTo` GSAP and explicit letter spans; the host seeks one local clock. Set `includeVideoAudio:true` for separate linked native sound strips. `revise_compositor_html` edits declared text and existing browser tracks; normal native batches edit transforms, masks, effects and timing. Refuse unsupported code rather than flattening it.
