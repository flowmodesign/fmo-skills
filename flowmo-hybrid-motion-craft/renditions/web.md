# Rendition: web

Keep a generated plate as a media element and requested copy/controls/graphics as independent editable page elements. Generate only through an available authorized producer, inspect its capability contract, and bind the actual successful output. Do not ask the producer to bake editable overlays into the clip.

Read `read_animations` when callable. Author saved web motion through `author_animation`, and update existing interaction IDs through `update_animation` when callable. Use the live schema's class selectors, seconds, GSAP-shaped JSON entries and supported triggers; never write a GSAP script, CSS animation, `@keyframes` or a manual animation loop into the document. Preserve a complete resting layout in saved CSS, with start states owned by motion.

Synchronize native beats with actual plate duration and movement. Verify load, scroll and interaction progression, readability, mobile/reduced-motion behavior and the ending with available preview tools. A screenshot proves a pose, not continuous choreography. Inspect native editability and actual media binding after a change.
