# Rendition: designer-motion

Keep plates as media and requested editable overlays as separate Designer elements. Read `read_document` for stable `data-dsn-id` targets and existing beats. Discover `set_motion` and, when callable, `set_interactions` before authoring. MotionSpec beats use milliseconds, supported presets/tweens and explicit from/to states; reuse beat IDs for edits. Never send compositor frame keys, `createShape`/`setMask`/`setEffect`, Animated wrappers, GSAP scripts or CSS animations to Designer.

Generate only through an available authorized producer such as `generate_video_asset`; inspect its actual model/input/duration contract and bind the returned successful asset. Preserve the native copy and controls over the clean plate. `page` may use supported scroll/interaction beats; `deck`, `motion`, `ad` and `video` use a seekable timeline with finite motion, readable holds and transitions. CSS 3D does not become an editable compositor world.

Inspect full-size pixels and native elements as well as saved beats. Preview the actual timeline or scroll progression with available tools, match reference moments, and repair the current revision. Verify that text and required graphics remain independently editable; claim render/export and playback checks only for tools and artifacts this editor actually supplies.
