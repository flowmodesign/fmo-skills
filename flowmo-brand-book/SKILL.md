# Native editable brand book

Compile the approved identity into a reusable document on a Designer deck. Use the linked brand record and current design-system context first; read relevant full Brain records when the context is partial and `read_record` is available. Preserve exact brand spelling, official logo source, palette roles/hex values, font families/weights and approved copy. Do not invent mission, values, rationale, measurements or mockups to complete the document.

Require only the slots used by the requested sections. A complete brand book needs the selected logo, palette and typography; unresolved choices are proposals, never implied approval. Existing approved slots need no second combined approval. If identity design is requested, finish the relevant native identity work before documenting its approved result. Preserve supplied assets rather than redrawing them.

Plan a concise section set: cover, approved concept/rationale, primary logo, supplied logo variants and usage, palette, typography, then approved applications. Omit unavailable optional sections or label an unresolved rule explicitly. Never fabricate a secondary/reverse mark, clear-space minimum, color standard or usage restriction. Include one application per spread or paired applications only when each remains legible.

For execution, use the actual Designer deck tools; read [references/native-deck.md](references/native-deck.md) before authoring. Keep copy, swatches, labels, layout shapes and placed images separate and editable. Review each complete slide, check exact brand values against their source and repair only confirmed misses within the existing request. Intentional brand glow, gradients and visual devices remain intact.

Export through the native Designer tools when available. Read `read_export_plan` for the exact deck page and source revision, then call `export_document` with that page, revision and requested `pptx` or `pdf` format. A changed revision requires a fresh plan. PPTX carries supported text/shapes as editable objects; some SVG/CSS treatments remain separate pictures. The agent PDF path is raster, without selectable text. Neither file is an animation or an editable vector master. Other PDF/PowerPoint choices remain available in the Designer UI; do not imply their behavior ran through this tool.

Deliver the saved native destination and the tool's actual file receipt/link. Distinguish verified generated bytes from persistent Storage, a confirmed asset row and a temporary browser Blob; never claim a filesystem download was confirmed. If export tools are unavailable, deliver the native book and label file export pending. Disclose fonts, unsupported effects, failed assets and warnings. A draft is not approval. Write or overwrite a Brain brand record only when the task already authorizes that persistence; a document request alone does not authorize changing the source brand. Respect read-only review requests. Continue authorized repairs while changed inputs or findings justify the next action. Honor explicit human retry and budget limits, Stop, source currentness and the real cost gate; this method supplies no attempt allowance. Do not repeat an unchanged failure or claim a failed or unverified result passed: report that blocker and the needed change.

Read [references/provenance.md](references/provenance.md) for the supplied source snapshot, license and explicit differences from the upstream fixed-template builder. If the user requires that exact canonical template or its approval-state/LibreOffice contract, report the missing adapter instead of substituting this native recipe.
