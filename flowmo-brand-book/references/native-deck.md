# Designer deck adapter

This route uses native markup, stylesheet, beat and slide tools. It does not require a provider CLI, external office application or paid generation. Use existing approved assets unless new generation is part of the request and a callable generation tool plus spending authority are present.

## Authoring

1. Resolve the native deck destination. On an existing deck, use its current saved document. If creating a separate document is requested and `add_page` is available, announce the new page and add `kind: "deck"`, then read the scaffold. Never replace an unrelated page with guidelines.
2. Read `read_document` for existing element IDs, stylesheet and motion state. On an empty or explicitly replaceable scaffold, `write_document` accepts body markup only. For an existing book, use `edit_element`, `insert_element` and `remove_element` on located sections; a whole-body replacement discards anchored IDs and comments.
3. Keep one slide root per section as a direct child of `.dsn-stage`, with `data-dsn-slide="<stop-beat-id>"`. Stage/slide layout belongs in `set_stylesheet`; do not hand-author `data-dsn-id`, inline styling or a script. The parser assigns native element IDs. Re-read those IDs before motion targeting.
4. Use `set_motion` to bind a supported minimal beat to each slide root and include those beat IDs in `stops`. Stops are beat IDs, never element IDs. Set loop to `once`; use the tool's current schema for the beat shape. Do not hide slide boxes yourself with `display` or an exit beat: native slide isolation shows the current slide. Review at each slide's completed frame.
5. Keep real text nodes for brand prose, HEX/RGB labels and font specimens. Use actual approved font faces, SVG/image URLs and intrinsic image proportions. Derive RGB labels deterministically from known hex values; do not guess CMYK, Pantone or minimum logo geometry. Show approved variants only.

`read_slides` gives ordered, numbered slides, markup and notes. `check_slides` checks size, overflow, coverage and slide bindings. Inspect `measurement` and `not_checked`: static fallback cannot certify rendered typography, crops or contrast. Pair geometry checks with rendered review of every completed slide; intentional whitespace can be valid, but must serve this document's hierarchy rather than hide missing content. Do not claim to write speaker notes: the current agent tools only read them.

## Native editability and file exports

- The saved Designer document retains separate text, shapes and media. A placed logo is an asset object; that does not make its vector paths editable.
- The Designer export UI's PowerPoint choice defaults to editable. The active export path measures completed frames, writes text boxes and supported shapes, and carries images, SVG and unsupported CSS effects as placed pictures. Choose the flat option only when the user requests exact-picture slides and accepts that limitation.
- Fonts can require installation in the recipient's office application. Export warnings about missing fonts, failed assets or slides without editable text must be disclosed and resolved when possible. Do not claim all objects are vector-editable or pixel-identical.
- PDF export preserves the composed appearance through the selected supported export path. Fixed-stage browser exports may be raster; desktop/vector paths differ. Verify the actual file before claiming searchable text, font embedding or visual parity with the PPTX.
- The native deck agent adapter uses `read_export_plan`, then `export_document` with the returned exact page ID/source revision and `pptx` or `pdf`. Its PPTX path is editable; its PDF path is raster. It rejects stale sources and incomplete page counts, reopens actual generated bytes and reports SHA-256/byte length, page count and actual PPTX object counts. Those checks do not prove full visual parity or recipient font availability.
- Read the delivery receipt: `storage_and_asset` confirms Storage plus an asset metadata ID; `storage_only` reports missing metadata; `session_only` is a temporary Blob link. Session links expire after 30 minutes, editor/browser close or six newer exports. `download_confirmed` stays false; generating a file or linking it does not confirm that the recipient saved it. No print dialog fallback is used by the agent adapter.

For completed files, compare slide count/order to `read_slides`, inspect each rendered page, confirm logo proportions, exact visible text, palette labels, loaded fonts and the absence of placeholders. Test at least one text box and one shape for editability in the actual PPTX when the available inspection path supports it. Name anything unverified rather than claiming the bundle passed.
