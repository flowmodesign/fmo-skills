# Rendition: designer-motion

Read `read_document` for saved beats and stable `data-dsn-id` targets. Discover `set_motion` and, when callable, `set_interactions` schemas. Designer uses MotionSpec beats in milliseconds, supported presets/tweens and explicit from/to states. Reuse beat IDs; read the complete spec before replace. Split/mask/stagger must use declared fields. Never send compositor frame keys/commands, GSAP scripts, CSS animations or `@keyframes`.

`page` may use native scroll beats and interaction triggers. `deck`, `motion`, `ad`, `video` seek a timeline: no scroll beats, finite repeats, readable holds and transitions. Keep requested copy/controls native over plates. Inspect saved beats, rendered reference moments and full timeline/scroll playback with available tools; recheck the changed revision and editability. Claim only exposed playback/render/export/3D capabilities.
